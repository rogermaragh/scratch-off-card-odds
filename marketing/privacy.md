# Privacy Policy

**ScratchOffCardOdds**
Last updated: 24 August 2026

## The short version

ScratchOffCardOdds collects nothing. There is no account, no analytics, no advertising
and no third-party SDK of any kind. Nothing you do in the app is transmitted
anywhere.

## What the app stores, and where

Everything below lives only on your device, inside the app's own container, and
is deleted when you delete the app.

| Stored | Why | Leaves the device? |
| --- | --- | --- |
| Your selected state (e.g. `NC`) | So the app opens where you are | No |
| Your appearance choice | So light/dark sticks | No |
| A cached copy of the lottery data file | So the app works offline | No |

## Location

If you allow it, the app asks for your location **once**, on first launch, to
work out which state's games to show.

- The coordinates are reverse-geocoded **on your device** into a two-letter
  state code.
- Only that state code is kept. The coordinates are discarded immediately and
  are never written to disk.
- Nothing is transmitted. The app has no server to transmit to.
- Declining is fully supported — pick your state from the list instead. No
  feature is withheld.

You can revoke access at any time in Settings → Privacy & Security → Location
Services → ScratchOffCardOdds.

## Network activity

The app makes one kind of request: downloading its own published data file
(lottery results and scratch-off prize counts). That request contains no
personal information — it is the same file for every user, and your device
sends nothing but a standard HTTP request for it.

If no remote source is configured, the app uses the copy bundled at build time
and makes no network requests at all.

## Children

ScratchOffCardOdds is not directed at children and displays lottery information intended
for adults. We do not knowingly collect information from anyone, of any age,
because we do not collect information.

## Third parties

There are none. No analytics provider, no crash reporter, no advertising
network, no attribution SDK. The app's dependency list is empty.

## Data sources

Lottery results and prize inventories are read from publicly published state
lottery sources, including New York State's open data portal and the public
websites and APIs of individual state lotteries. ScratchOffCardOdds is not affiliated
with, endorsed by, or connected to any lottery.

## Changes

If this policy ever changes, the updated version will be published here and the
date at the top will change. Since the app collects no data, any change is far
more likely to be a clarification than a new practice.
